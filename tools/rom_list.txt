# ROM list: the single source of truth for what is built and tested.
# Read by the Makefile (build, all, .PHONY, test), tools/run_rom_tests.sh and
# tools/check_test_list.sh. One ROM per line, whitespace separated:
#   stem   kind   exrom   expect   [note]
# stem   rom/<stem>.asm (or rom/bench/<stem>.asm for kind bench)
# kind   smoke|test    self-checking, built by the generic rule, run by `make test`
#        visual|bench  built by the generic rule, no pass/fail border verdict
#        product|special|exrom   built by explicit Makefile rules
# exrom  ROM 1 image for `make test`: none = stock-shaped placeholder (8K of $00),
#        gfx = build/graphics_exrom.bin, a5 = 8K of $A5, - = not applicable
# expect final border colour that means PASS (4 for the green convention),
#        skip = deliberately not run by `make test` (see the note), - = no verdict
# Keep rom/forth_smoke*.asm and rom/test_*.asm complete here:
# tools/check_test_list.sh enforces it in `make check`.
